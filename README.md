# iad case study (duck.design)

Case study canvas for the duck.design case-studies page.

- `index.html` – view version for review. Same page as `embed.html`, with the Inter and Sentient fonts bundled from `fonts/`.
- `embed.html` – the version for the site. It is meant to sit inside the site through an iframe, and the site provides the fonts. All classes use the `cc-iad` prefix, and there are no external requests.
- `img/` – webp images and the iad logo, each under 400 KB.
- `cover-552x368.webp` and `cover-552x368@2x.webp` – the card cover.
